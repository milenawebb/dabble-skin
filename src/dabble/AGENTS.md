# Page presentation boundaries
- Include all skin CSS in root-linked global CSS and retain CSS side effects; absolute percentage-based paint sizing prevents backing-store dimensions from growing the frame before CSS arrives.
- Keep the reusable player, local button primitives, frame/skin styles, and tests in `src/dabble/`; all consumers use its `index.ts` entry, and skin imports never depend on demo files, so it can be reused without the landing page.
- Keep the pinned Bun controls-feature patch in dev/production so Video.js alone owns the 2.5-second idle and paused/ended holds; test its actual runtime on upgrades.
- Desktop/tablet trays initialize open without enabling painting and change state only through explicit ledge/Escape/P actions; use measured player width for two-zone shelves at 670–1000px and three rows below, keeping phone state separate.
- Suppress desktop/tablet controls only during frame strokes plus one-second recovery, never for tray openness or fullscreen; measure caption clearance from the rendered bar top while preserving docked phone positioning.
- Publish decorative shortcut feedback through the existing Video.js coordinator and guarded custom actions; page listeners never run player actions.
- Gate page keycap audio on an explicit sound preference and a trusted page gesture; offering player sounds is not itself opt-in consent.
- Self-accept painting-hook development updates with a full page reload so hook-layout edits cannot reuse incompatible React state slots; saved strokes restore normally.
- Show only a pointer-transparent centered reminder after video dragging with open tools; use no opening outline or first-stroke tracking, and leave plain Video.js taps untouched.
- Use PlayerLabels only for open paint-panel tools, never playback or ledge buttons; preserve descriptive button names and selected-brush fallback so labels never compete or clip.
- Render use-case mini frames through the existing paint engine with fixed seeded strokes after section intersection; thumbnail assets stay static and non-interactive.
